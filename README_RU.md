# PixelForge — настольный графический редактор

PixelForge — независимый стартовый проект редактора изображений для Windows. Он не является продуктом Adobe и не использует код, логотипы или фирменные материалы Adobe.

## Что уже работает
- Создание холста с заданными размерами и цветом фона
- Открытие локальных изображений
- Слои: добавление, выбор, видимость, изменение порядка, удаление
- Кисть, ластик, линия, прямоугольник, текст
- Размер кисти и выбор цвета
- Яркость, контраст и насыщенность (применяются к выбранному слою)
- Отмена/повтор (Ctrl+Z / Ctrl+Y)
- Экспорт PNG через диалог Windows
- Локальная обработка файлов

## Запуск на Windows
1. Установите Node.js LTS с официального сайта https://nodejs.org/
2. Распакуйте архив в папку.
3. Откройте PowerShell в папке PixelForge.
4. Выполните:
   ```powershell
   npm install
   npm start
   ```
5. Для создания установщика Windows:
   ```powershell
   npm run dist
   ```
   Установщик появится в папке `dist`.

## Важные ограничения первой версии
- Это рабочий MVP, а не полная замена Photoshop.
- Слои пока растровые; нет полноценного PSD-импорта/экспорта.
- Инструмент перемещения и рамка кадрирования пока зарезервированы.
- AI-кнопки — интерфейсные точки расширения. Настоящие AI-модели не встроены, внешняя подписка не требуется.
- Перед распространением проверьте лицензии всех добавляемых библиотек, шрифтов и моделей.

## Правовая аккуратность
Название PixelForge и интерфейс созданы как самостоятельный проект. Перед коммерческим выпуском рекомендуется проверить доступность названия и товарного знака в целевых странах, а также добавить собственную политику конфиденциальности и условия использования.

## Сборка готового EXE без Node.js на компьютере пользователя

В репозитории уже добавлен GitHub Actions workflow `.github/workflows/build-windows.yml`.
Он собирает Windows-установщик на облачном Windows runner:
1. Загрузите исходники проекта в новый GitHub-репозиторий.
2. Откройте вкладку Actions и разрешите запуск workflows, если GitHub попросит.
3. Выберите `Build PixelForge for Windows` → `Run workflow`.
4. После завершения откройте запуск workflow и скачайте artifact `PixelForge-Windows-Installer`.
5. Внутри будет `PixelForge-Setup-1.0.0.exe`.

Node.js на компьютере, где будет использоваться готовый установщик, не нужен.
Для самой облачной сборки GitHub устанавливает Node.js автоматически.
